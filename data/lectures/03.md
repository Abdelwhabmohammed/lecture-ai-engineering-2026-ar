# Lecture 03 وكلاء الذكاء الاصطناعي

## الأهداف

- فهم أن البنية الأساسية لوكيل الذكاء الاصطناعي هي «نموذج + حلقة + أدوات»
- بناء وكيلك الخاص لدعم التعلم باستخدام أدوات Pydantic AI وتشغيله

## النقاط الرئيسة

1. **ما الوكيل؟**: نظام يحقق هدفًا عبر حلقة يستدعي فيها نموذج لغوي كبير الأدوات، ويفحص النتائج، ويقرر خطوته التالية.
2. **الأدوات**: ينظر النموذج إلى أسماء الأدوات وأوصافها وأنواع وسيطاتها لطلب استدعائها، بينما ينفذ البرنامج الاستدعاء. تؤثر صياغة الوصف في السلوك.
3. **تكلفة حلقة الوكيل**: يؤثر تعدد استدعاءات النموذج اللغوي الكبير لسؤال واحد تأثيرًا ملحوظًا في وقت الاستجابة والتكلفة وحدود المعدل.
4. **الغلاف البرمجي**: برنامج مثل Claude Code أو Pi يحيط بالنموذج بحلقة وأدوات وواجهة مستخدم. ‏Pi غلاف بسيط بأربع أدوات مدمجة فقط (read وwrite وedit وbash).
5. **أطر العمل**: يعرّف Pydantic AI (الإطار الرئيس هنا) الأدوات والمخرجات بأنواع، ويتيح فحص السلوك دون استدعاءات API باستخدام نموذج اختبار (TestModel). ‏ADK هو إطار Google لتطوير الوكلاء.
6. **ضوابط الأمان وإشراك الإنسان**: في العمليات التي يصعب التراجع عنها، مثل الكتابة، قيّد الصلاحيات أو اطلب تأكيدًا بشريًا.

## ما ستجربه في التمارين

- اطرح على وكيل يبحث في المسرد الأسئلة نفسها التي طرحتها في Lecture 01، وتحقق من تحسن الإجابات
- اقرأ الأدوات المستدعاة والوسيطات المستخدمة معها
- أضف أداة واحدة
