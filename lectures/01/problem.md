# تمارين وواجبات Lecture 01: إعداد بيئة التطوير وطرح سؤال على نموذج لغوي كبير

## أهداف هذه المحاضرة

- افتح نسختك المتفرعة في Codespaces واستدعِ Gemini API
- أجرِ تعديلات صغيرة على الشيفرة بمساعدة GitHub Copilot
- سلّم العمل عبر Pull Request من فرع عمل (ستستخدم طريقة التسليم هذه في المحاضرات اللاحقة أيضًا)

## ما ينبغي تحضيره

- حساب GitHub شخصي (قد تمنع إعدادات المؤسسة استخدام Codespaces أو Copilot في الحسابات التي تديرها شركة)
- حساب Google شخصي (قد تعطل إعدادات المسؤول AI Studio في حسابات Google Workspace التابعة للشركات)

## التمارين (45 دقيقة)

### 1. أنشئ نسخة متفرعة من مستودع المقرر

استخدم زر **Fork** أعلى يمين مستودع المقرر لإنشاء نسخة متفرعة في حسابك. أنجز كل العمل اللاحق داخل نسختك.

### 2. أنشئ مفتاح Gemini API

أنشئ مفتاح API وانسخه في [Google AI Studio](https://aistudio.google.com/apikey).

> مفاتيح API أسرار. لا تلصقها في الشيفرة أو المحادثات أو الالتزامات. إذا تسرّب مفتاح، فاحذفه في AI Studio وأنشئ مفتاحًا جديدًا.

### 3. سجّله ضمن أسرار Codespaces

في GitHub **Settings → Codespaces → Secrets → New secret**، سجّل:

- الاسم: `GEMINI_API_KEY`
- القيمة: المفتاح الذي أنشأته في الخطوة 2
- حق الوصول إلى المستودع: اختر **نسختك المتفرعة**

> سجّل السر قبل بدء Codespaces. إذا سجلته بعد التشغيل، فأعد تشغيل Codespace.

### 4. شغّل Codespaces

في نسختك المتفرعة، اختر **Code → Codespaces → Create codespace on main**. يستغرق إعداد البيئة بضع دقائق أول مرة. نفّذ الأمر التالي في الطرفية وتحقق من نجاح الاختبارات.

```bash
uv run pytest -q
```

### 5. اسأل نموذجًا لغويًا كبيرًا دون أدوات

```bash
uv run python -m app.ask "ما هو LoRA؟"
uv run python -m app.ask "ما مستويات الواجب الثلاثة في مقرر AIE2026؟"
```

السؤال الأول عن مصطلح عام، لذا يُتوقع أن تكون الإجابة صحيحة إجمالًا. أما الثاني فعن «مستويات الواجب الثلاثة» الخاصة بهذا المقرر. النموذج المباشر لا يعرف هذا المقرر؛ فقد يقول «لا أعرف» أو يقدم جوابًا يبدو معقولًا استنادًا إلى المعرفة العامة. المعلومة الصحيحة موجودة في `homework-levels` داخل `data/glossary.json`. قارنها بإجابة النموذج.

إذا توفر وقت، فجرّب أسئلة أخرى خاصة بالمقرر. لاحظ أن السؤال نفسه قد يعطي إجابات مختلفة في مرات تشغيل مختلفة، وأن النموذج قد يجيب بثقة حتى حين لا يعرف.

```bash
uv run python -m app.ask "ما وسم lecNN-start في مقرر AIE2026؟"
uv run python -m app.ask "ماذا سنتعلم في Lecture 02 من AIE2026؟"
```

### 6. استخدم Copilot لعرض عدد الرموز

عند `TODO(تمرين Lecture 01)` في `app/ask.py`، عدّل الشيفرة لعرض عدد رموز الإدخال والإخراج. يمكنك استخدام إكمال Copilot أو المحادثة معه. اقرأ الشيفرة المقترحة وافهمها قبل قبولها.

### 7. أنشئ فرعًا وافتح Pull Request

```bash
git switch -c lec01
# املأ lectures/01/answer.md
git add -A
git commit -m "Lecture 01 exercises"
git push -u origin lec01
```

في GitHub، أنشئ Pull Request من `lec01` إلى `main` داخل نسختك المتفرعة. **تحقق من أن المستودع المستهدف هو نسختك المتفرعة** (لا تفتح Pull Request في مستودع المقرر).

### 8. أوقف Codespaces

اختر "Codespaces" أسفل اليسار ← **Stop Current Codespace**. بقاؤه قيد التشغيل يواصل استهلاك حصتك المجانية.

## الواجب (أكمل أي مستوى واحد)

| المستوى | المهمة |
|---|---|
| أساسي | شغّل كل سؤال ثلاث مرات باستخدام نماذج مختلفة (متغير البيئة `AIE_MODEL`) أو قيم مختلفة لدرجة الحرارة، ثم لخّص الفروق في answer.md |
| تطبيقي | عدّل `app/ask.py` ليدعم أسئلة المتابعة مع الاحتفاظ بسجل المحادثة |
| متقدم | قِس زمن الاستجابة وعدد الرموز، وقارن نماذج أو أسئلة متعددة. ناقش صلتها بحدود المعدل في الحصة المجانية |

مثال لتغيير النموذج:

```bash
AIE_MODEL=gemini-3.5-flash uv run python -m app.ask "ما هو LoRA؟"
```
